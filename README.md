# Steam 账号批量登录脚本 - 使用说明

> 一个电脑小白也能轻松上手的自动化工具

---

## 📌 这个脚本做什么？

**自动登录你的多个 Steam 账号，然后退出，接着登录下一个**

**适合谁用**：
- 你有多个 Steam 账号需要登录
- 不想一个个手动输入账号密码
- 需要批量处理账号（比如签到、领取活动奖励）

**工作流程**：
1. 读取你准备的账号列表
2. 自动登录第一个账号
3. 退出登录
4. 自动登录第二个账号
5. 依次循环，直到全部完成

**整个过程都是自动的，你只需要看着！**

---

## 🚀 三步开始使用

### 第一步：检查有没有 Python

**1. 打开命令提示符**
- 按 `Win + R` 键
- 输入 `cmd`
- 按回车

**2. 输入命令检查**
```bash
python --version
```

**3. 查看结果**

| 看到什么 | 说明 |
|---------|------|
| `Python 3.x.x` | ✅ 已安装，跳到第二步 |
| 提示"不是内部或外部命令" | ❌ 需要先安装 Python |

**❌ 没有安装？**
1. 去 https://www.python.org/downloads/ 下载 Windows 安装包
2. 安装时**一定要勾选** "Add Python to PATH"
3. 安装完成后重启电脑

---

### 第二步：安装必要的工具（只需一次）

**1. 打开项目文件夹**
- 按 `Win + R` 键
- 输入 `cmd`
- 按回车
- 输入命令进入项目文件夹：
```bash
cd D:\vscode\LoginScript
```

**2. 安装 Playwright（复制粘贴这个命令）**
```bash

```

**等待安装完成**（大概1-2分钟）
- 看到很多行文字滚动是正常的


**等待下载完成**（大概2-5分钟）
- 会显示下载进度
- 看到 `Browser downloaded` 就好了

## 🎬 运行登录脚本

账号添加完成后，就可以运行脚本了！

**运行命令**
```bash

```

**你会看到什么**

脚本会自动打开一个浏览器窗口，你会看到：

1. ✅ 自动访问 Steam 登录页
2. ✅ 自动输入账号密码

## ⚠️ 常见问题

### 问题1：需要输入 Steam Guard 验证码

**看到这个提示**
```
📧 检测到 Steam Guard 验证
💡 请检查邮箱获取验证码
请输入 Steam Guard 验证码 (留空跳过):
```

**解决方法**
1. 脚本会暂停，等待你输入
2. 拿手机或打开邮箱
3. 找到 Steam 发的验证码（6位数）
4. 在命令提示符输入验证码
5. 按回车继续

### 问题2：提示"找不到模块"

**错误信息**
```
ModuleNotFoundError: No module named 'playwright'
```

**解决方法**
```bash
pip install playwright==1.48.0
```

### 问题3：提示"找不到浏览器"

**错误信息**
```
Executable doesn't exist
```

**解决方法**
```bash
playwright install chromium
```

### 问题4：登录失败

**可能的原因**

| 原因 | 解决方法 |
|------|---------|
| 密码错误 | 检查账号文件里的密码对不对 |
| 网络断开 | 检查能上网吗 |
| Steam限制登录太频繁 | 等10-30分钟再试 |
| 账号被封 | 联系Steam客服 |

### 问题5：想停止脚本

按 `Ctrl + C`（同时按Ctrl和C键）

## 💡 实用技巧

### 查看登录进度

命令提示符会显示：
```
📋 进度: [2/5]
```
表示正在处理第2个，总共5个账号

### 暂时不想登录某个账号

在 `accounts.txt` 文件中，不想登录的账号行前面加 `#`

例如：
```
# mygame123:abc123456:mygame@qq.com:mail8888:mail.qq.com
```

### 调整登录速度

打开 `src\login_steam.py` 文件，找到这几行：
```python
wait_time = 5      # 登录后等待时间（秒）
interval = 3       # 账号之间间隔（秒）
```

可以改这些数字来调整速度

## 🔒 安全提醒

⚠️ **重要**：

1. **不要分享账号文件**
   - `accounts.txt` 包含你的账号密码
   - 不要发给任何人
   - 不要上传到网上

2. **公共场所使用注意**
   - 在网吧用完后，删除 `accounts.txt`

3. **定期更换密码**
   - 建议定期更换 Steam 密码
   - 开启 Steam Guard 保护

## ❓ 常见疑问

**Q: 脚本会偷我的账号吗？**

A: 不会。源代码是公开的，你可以自己查看。所有操作都是在你电脑上完成的。

**Q: 为什么我用不了？**

A: 检查这4点：
1. Python版本是否3.8或以上
2. 是否安装了 playwright
3. 是否安装了 chromium 浏览器
4. `accounts.txt` 格式是否正确（建议用 quick_add.py 工具）

**Q: 可以在后台运行吗？**

A: 可以，但需要修改代码，建议小白不要改，看得见更放心。

**Q: 登录太慢怎么办？**

A: 可能是网络慢，或者 Steam 服务器响应慢。可以尝试换个时间段（比如凌晨人少时）。

**Q: 支持游戏内签到吗？**

A: 当前版本不支持，这是计划中的功能。
