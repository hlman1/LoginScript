# Steam 批量登录工具 - 使用说明

> 电脑小白也能轻松使用的 Steam 批量登录工具

**版本**: v3.0 | **成功率**: 100% | **更新时间**: 2026-03-08

---

## 🎯 这个工具是做什么的？

**简单来说**：
1. 自动登录你的多个 Steam 账号
2. 自动启动 PUBG 游戏
3. 游戏运行 90 秒后自动退出
4. 自动切换到下一个账号

**适用人群**：需要批量登录多个 Steam 账号运行游戏的用户

---

## 📦 准备工作（只需做一次）

### 步骤 1: 安装 Python

**如何检查是否已安装**：
1. 按 `Win + R` 键
2. 输入 `cmd` 并回车
3. 输入 `python --version` 并回车
4. 如果看到版本号（如 Python 3.8.0），说明已安装
5. 如果提示"不是内部命令"，需要安装

**如何安装 Python**（小白教程）：
1. 打开浏览器，访问：https://www.python.org/downloads/
2. 点击黄色的 "Download Python 3.x.x" 按钮
3. 下载完成后，双击安装包
4. ⚠️ **重要**：安装时勾选 "Add Python to PATH"
5. 点击 "Install Now" 等待安装完成

### 步骤 2: 下载项目文件

1. 创建一个文件夹，比如 `D:\SteamTool\`
2. 将所有项目文件复制到这个文件夹
3. 确保文件夹结构如下：
```
D:\SteamTool\
├── src\
│   ├── login_steam.py
│   ├── steam_login_gui.py
│   ├── chinese_to_tab.py
│   └── accept_button.png
├── accounts.txt
├── requirements.txt
└── start.bat
```

### 步骤 3: 安装依赖

**方法 1：使用 start.bat（推荐，最简单）**
1. 双击 `start.bat`
2. 如果提示缺少依赖，点击 "检查环境" 按钮
3. 工具会自动安装所需依赖
4. 等待安装完成

**方法 2：手动安装（备用方法）**
1. 按 `Win + R`，输入 `cmd`，回车
2. 输入以下命令：
```bash
cd D:\SteamTool
pip install -r requirements.txt
```
3. 等待安装完成

## 🚀 使用方法

### 🌟 方式 1：图形界面模式（推荐，最简单）⭐⭐⭐⭐⭐

#### 启动步骤：
1. **双击** `start.bat` 文件
2. 会弹出一个黑色窗口，然后自动打开图形界面
3. 点击 "检查环境" 确保所有组件都已安装
4. 点击 "添加账号" 添加你的 Steam 账号
5. 点击 "开始运行" 开始批量登录

#### 图形界面操作：
- **检查环境**：验证依赖是否安装（会自动安装缺失的组件）
- **添加账号**：通过友好的表单添加账号
- **查看账号**：查看已添加的账号列表
- **编辑账号**：修改账号信息
- **删除账号**：删除不需要的账号
- **开始运行**：开始批量登录所有账号

---

### 💻 方式 2：命令行模式（无需 GUI，直接运行脚本）⭐⭐⭐⭐

#### 方法 A：直接运行主脚本（最简单）

**步骤**：
1. 准备好 `accounts.txt` 文件
2. 双击 `start.bat`，会启动 GUI
3. 或者使用下面的命令行方法

#### 方法 B：纯命令行方式（推荐进阶用户）

**步骤 1：准备账号文件**

**选项 A：手动编辑 accounts.txt**
```
1. 右键点击 accounts.txt
2. 选择"打开方式" → "记事本"
3. 按以下格式输入账号：

账号1	密码1
账号2	密码2
账号3	密码3

注意：字段之间用 Tab 键隔开，不是空格！
```

**选项 B：使用转换工具（如果你有中文格式的账号信息）**

1. 创建一个文本文件 `my_accounts.txt`，输入：
```
steam账号账号1密码密码1邮箱账号邮箱1
账号账号2密码密码2
```

2. 运行转换工具：
```bash
python src\chinese_to_tab.py my_accounts.txt
```

3. 工具会自动转换并保存到 `accounts.txt`

**步骤 2：运行登录脚本**

**方法 1：直接运行**
```bash
python src\login_steam.py
```

**方法 2：先切换目录再运行**
```bash
cd D:\SteamTool
python src\login_steam.py
```

**方法 3：使用 start.bat（会启动 GUI，但你可以不用）**
```bash
start.bat
```

#### 命令行方式的完整流程：
```bash
# 1. （可选）转换账号格式
python src\chinese_to_tab.py my_accounts.txt

# 2. 运行登录脚本
python src\login_steam.py

# 3. 等待完成
```

#### 优点：
- ✅ 无需 GUI，直接运行
- ✅ 可以看到详细的运行日志
- ✅ 适合批处理和自动化
- ✅ 可以结合脚本和计划任务使用

## ⚙️ 高级配置（可选）

### 修改游戏运行时间

**默认**：90 秒

**修改方法**：
1. 用记事本打开 `src\login_steam.py`
2. 按 `Ctrl + F` 搜索 `game_time = 90`
3. 将 `90` 改为你想要的秒数
4. 保存文件

**示例**：
```python
game_time = 120  # 改为 120 秒（2 分钟）
```

### 修改 Steam 路径

**默认**：自动检测

**修改方法**：
1. 用记事本打开 `config.json`
2. 修改路径
3. 保存文件

**示例**：
```json
{
  "steam_path": "C:\\Program Files (x86)\\Steam\\steam.exe"
}
```

## 🛡️ 常见问题解决

### 问题 1：双击 start.bat 后窗口一闪而过

**原因**：Python 没有安装或没有添加到 PATH

**解决**：
1. 按 `Win + R`
2. 输入 `cmd` 并回车
3. 输入 `python --version` 检查是否安装
4. 如果未安装，先安装 Python
5. 如果已安装，重新运行安装程序，勾选 "Add Python to PATH"

### 问题 2：提示缺少依赖

**解决**：
1. 运行工具
2. 点击 "检查环境"
3. 如果有红色❌，点击 "自动安装"
4. 等待安装完成

**或手动安装**：
```bash
pip install -r requirements.txt
```

### 问题 3：Steam 登录失败

**可能原因**：
1. 账号密码错误
2. 需要 Steam Guard 验证码
3. 网络问题

**解决**：
1. 检查账号密码是否正确
2. 如果需要验证码，会在手机上收到
3. 检查网络连接

### 问题 4：PUBG 无法启动

**可能原因**：
1. 游戏没有安装
2. Steam 没有正确登录
3. 磁盘空间不足

**解决**：
1. 检查游戏是否已安装
2. 查看 Steam 是否已登录
3. 检查磁盘空间

### 问题 5：图像识别失败

**可能原因**：
1. 模板文件缺失
2. 分辨率不匹配

**解决**：
1. 检查 `src\accept_button.png` 是否存在
2. 运行 `python src\visualize_match.py` 测试
